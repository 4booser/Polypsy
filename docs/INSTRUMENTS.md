# Паспорт методик

Статус каждой методики: источник, объём переноса, правовое положение и
что осталось выверить. Обновляется при каждом изменении инструментов
(`apps/api/src/instruments/`).

## Правовое положение — общее

Тексты пунктов воспроизведены из печатных пособий. **До клинического
применения** формулировки и права на использование должны быть согласованы
с правообладателем каждой методики. Система хранит и считает — юридическую
чистоту контента она обеспечить не может.

---

## СР-45 — склонность к суицидальным реакциям (П.И. Юнацкевич)

- **Файл:** `sr45.ts`
- **Источник:** Збірник методик для діагностики негативних психічних станів
  військовослужбовців. — К.: НДЦ ГП ЗСУ, 2016. — С. 89–96.
- **Перенесено:** 45 пунктов (uk/ru), ключи Sr (35) и шкалы лжи L (10),
  доли Sr=N/35, L=N/10, гейт достоверности L ≥ 0,6, перевёрнутая
  5-балльная градация, критические пункты с тревогами, safety-план.
- **Тексты пунктов — в сокращении** (полные в пособии).
- **Выверка:** структурно — валидатором и золотыми тестами; сверка ключей
  с печатной таблицей по `/surveys/:id/key` — **не проведена**.

## SAD PERSONS (Patterson et al., 1983)

- **Файл:** `sadPersons.ts`
- **Источник:** там же, С. 97–99.
- **Перенесено:** 10 пунктов, заполняет клиницист, интерпретация с
  рекомендациями вплоть до обязательной госпитализации.
- **Выверка:** пороги интерпретации совпадают с пособием; сверка — **не проведена**.

## Мини-мульт (сокращённый MMPI)

- **Файл:** `minimult.ts` + `minimult_items.ts`
- **Источник:** там же, С. 100–115.
- **Перенесено:** 71 пункт, ключи 3 шкал достоверности + 8 клинических,
  K-коррекция (Hs+0.5K, Pd+0.4K, Pt+K, Se+K, Ma+0.2K), T-нормы по полу.
- **Особенность:** для Ma в пособии нет норм — шкала честно остаётся сырой
  с пояснением.
- **Выверка:** золотой тест с ручным расчётом; сверка ключей — **не проведена**.

## БОО «Адаптивність-200» (МЛО)

- **Файл:** `mlo.ts` + `mlo_items.ts`
- **Источник:** Посібник з психодіагностики НПС.
- **Перенесено:** 200 пунктов, ключи 4 уровней, инвертированные таблицы
  стенов, композит ЛАП из ПР+КП+МН.
- **Открытые вопросы:**
  - **10 пунктов без украинского текста** (строки 197–206 `mlo_items.ts` —
    алкоголь/агрессия/неподчинение): распознавание PDF не справилось,
    подставлен русский; выверить по оригиналу.
  - **Таблица стенов ЛАП выведена суммированием** границ трёх шкал —
    проверить против печатной таблицы пособия.
- **Выверка:** не проведена.

## Демо-методики (`isDemo = true`)

«Скрининг эмоционального состояния», «Качество сна», «Контрольный замер» —
авторские демонстрационные, написаны для наполнения аналитики. Не являются
клиническими инструментами и помечены плашкой «демо». Реальные шкалы
(PHQ-9, GAD-7, BDI…) намеренно не воспроизводились — они защищены
авторским правом.

## Как выверять новую методику

1. Перенести пункты через «Вставить пункты из текста» в конструкторе.
2. Задать ключи, нормы, полосы; прогнать «Проверить структуру».
3. Распечатать `/surveys/:id/key` и сверить с пособием построчно.
4. Составить эталонный протокол (ответы → баллы руками по пособию) и
   добавить золотой тест в `apps/api/src/instruments/__tests__/`.
5. Отметить статус в этом файле.
