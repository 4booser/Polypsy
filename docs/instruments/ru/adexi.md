## 1. Назначение

Четырнадцать утверждений о трудностях с рабочей памятью и сдерживанием (тормозным контролем) в повседневной жизни (ADEXI; Holst, Thorell, 2018; www.chexi.se). Результат — три средних балла от 1 до 5: общий, рабочая память и тормозной контроль; больше — больше трудностей. Норм и порогов нет: разработчик пишет, что они ещё не установлены, поэтому балл сравнивают с прежними замерами самого человека, а не с границей. Методика не диагностирует СДВГ или последствия травмы — она показывает, как человек сам оценивает свои трудности; результат пациенту не показывается. Русский текст — перевод с сайта разработчика (D. Zarina, O. Stanevich, M. Korman; Ariel University); инструкция приведена к электронной форме.

**Инструкция обследуемому:** Ниже вы найдете несколько утверждений. Для каждого выберите ответ, который лучше всего описывает вас как личность. Люди, которые вас знают, могут думать иначе, но нам важно узнать ваше собственное мнение о себе. Постарайтесь отвечать как можно честнее.

## 2. Источник

- **Записано в системе** (журнал установки каталога, на языке записи): ADEXI (Adult Executive Functioning Inventory), Holst, Thorell, Int J Methods Psychiatr Res 2018 (Karolinska Institutet, www.chexi.se) — вільне використання для клініцистів і дослідників за заявою правовласника; без смуг — норм у розробника немає. Український текст — робочий переклад, російський — переклад із сайту правовласника (Zarina, Stanevich, Korman)
- **Публикация по досье**: Holst Y, Thorell LB. Adult executive functioning inventory (ADEXI): Validity, reliability, and relations to ADHD. Int J Methods Psychiatr Res. 2018;27(1):e1567. doi:10.1002/mpr.1567 (PMC6877129). Бланк: «Adult Executive Functioning Inventory (ADEXI) Self-report», www.chexi.se (PDF https://www.chexi.se/onewebmedia/English%20ADEXI%20self-report.pdf); подшкалы — https://www.chexi.se/onewebmedia/ADEXI%20subscales.pdf.
- **Полосы по досье** (на языке досье): Полос нет у правообладателя: «normative data are unfortunately not yet available for any of the questionnaires. This means that at the moment, these instruments are most useful as research tools as it is not possible to determine exact cut-offs for different ages without normative data. […] Until norms are available, the only indication of where to draw cut-offs is to use the means and standard deviations that are presented in the studies that have used the instruments.» Средние (SD) из Holst & Thorell 2018, Table 4, шведские взрослые, средний возраст около 26–27 лет: общий — СДВГ (n = 51) 3.41 (.71), клинический контроль без СДВГ (n = 46) 2.50 (.80), неклиническая группа (n = 44) 2.03 (.61); торможение — 3.46 (.84), 2.72 (.92), 2.14 (.71); рабочая память — 3.39 (.78), 2.39 (.90), 1.97 (.68). Это ориентир для специалиста, а не порог: в системе полос не заводить.
- **Лицензия по досье**: свободна для клиницистов и исследователей — 1) Бесплатно для клиницистов и исследователей; для языковых версий с сайта разрешение не требуется. 2) Для языка, которого на сайте нет (украинский), разработчик просит связаться с Lisa Thorell и приглашает переводить по шаблонам сайта — учреждению написать ей и передать украинский перевод. 3) Разработчик просит присылать публикации с использованием методики. 4) Первая цитата — с главной страницы https://www.chexi.se/, остальные — со страницы переводов.
- **Решение досье** (на языке досье): завести без полос — правообладатель разрешает бесплатное использование клиницистами, текст, ключ подшкал и способ подсчёта (средние) есть в его документах; норм и порогов нет у самого разработчика. Русский текст — перевод с сайта правообладателя, украинский — рабочий перевод (и письмо Lisa Thorell).

## 4. Шкалы

### ADEXI — Исполнительные функции: общий балл

- **Тип:** клиническая (содержательная)
- **Ключ:** пункты 1–14 (14), балл выбранного варианта
- **Обратные пункты:** нет
- **Сырой балл:** среднее вкладов пунктов, на которые есть ответ (сумма ÷ количество ответов); округление до 0,001
- **Нормирование:** нет: итог — сырой балл
- **Диапазон сырого балла:** от 1 до 5
- **Минимальная доля ответов:** 0,8 (общее правило системы) — не меньше 12 из 14 заданных пунктов; меньше — шкала не вычислена (не 0). Пункты, скрытые условием показа, в знаменатель не идут.
- **Описание в системе:** Среднее всех 14 пунктов, 1–5; больше — больше трудностей. Норм и порогов нет (позиция разработчика). Ориентир, а не граница — средние (SD) у Holst, Thorell, 2018, шведские взрослые около 26–27 лет: с СДВГ — 3,41 (0,71), клиническая группа без СДВГ — 2,50 (0,80), неклиническая — 2,03 (0,61).

_Полос нет — система показывает только балл, без интерпретации и без тревоги по баллу._

### WM — Рабочая память

- **Тип:** клиническая (содержательная)
- **Ключ:** пункты 1, 2, 5, 7–9, 11–13 (9), балл выбранного варианта
- **Обратные пункты:** нет
- **Сырой балл:** среднее вкладов пунктов, на которые есть ответ (сумма ÷ количество ответов); округление до 0,001
- **Нормирование:** нет: итог — сырой балл
- **Диапазон сырого балла:** от 1 до 5
- **Минимальная доля ответов:** 0,8 (общее правило системы) — не меньше 8 из 9 заданных пунктов; меньше — шкала не вычислена (не 0). Пункты, скрытые условием показа, в знаменатель не идут.
- **Описание в системе:** Среднее пунктов 1, 2, 5, 7, 8, 9, 11, 12, 13; 1–5. Норм и порогов нет. Ориентир (Holst, Thorell, 2018): с СДВГ — 3,39 (0,78), клиническая группа — 2,39 (0,90), неклиническая — 1,97 (0,68).

_Полос нет — система показывает только балл, без интерпретации и без тревоги по баллу._

### INH — Тормозной контроль

- **Тип:** клиническая (содержательная)
- **Ключ:** пункты 3, 4, 6, 10, 14 (5), балл выбранного варианта
- **Обратные пункты:** нет
- **Сырой балл:** среднее вкладов пунктов, на которые есть ответ (сумма ÷ количество ответов); округление до 0,001
- **Нормирование:** нет: итог — сырой балл
- **Диапазон сырого балла:** от 1 до 5
- **Минимальная доля ответов:** 0,8 (общее правило системы) — не меньше 4 из 5 заданных пунктов; меньше — шкала не вычислена (не 0). Пункты, скрытые условием показа, в знаменатель не идут.
- **Описание в системе:** Среднее пунктов 3, 4, 6, 10, 14; 1–5. Норм и порогов нет. Ориентир (Holst, Thorell, 2018): с СДВГ — 3,46 (0,84), клиническая группа — 2,72 (0,92), неклиническая — 2,14 (0,71).

_Полос нет — система показывает только балл, без интерпретации и без тревоги по баллу._

## 8. Известные отличия от первоисточника

- Три шкалы — средние баллов пунктов 1–5 (документ правообладателя «Subscales for ADEXI»): рабочая память — пп. 1, 2, 5, 7, 8, 9, 11, 12, 13; тормозной контроль — пп. 3, 4, 6, 10, 14; общий балл — все 14.
- Полос нет — норм у разработчика нет; средние групп Holst, Thorell (2018) стоят в описаниях шкал как ориентир. Результат обследуемому не показывается.
- Украинский текст — рабочий перевод. Русский — перевод с сайта правообладателя дословно; изменена только инструкция под электронную форму (ответ выбирают у каждого утверждения).
