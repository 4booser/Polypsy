## 1. Назначение

Три вопроса о том, насколько часто человек чувствует нехватку общения, отстранённость и изоляцию. Результат — сумма 3–9, выше означает более сильное чувство одиночества. Полос интерпретации у методики НЕТ: в первоисточнике пороги не установлены, а распространённое деление «3–5 / 6–9» взято из методичек и не валидировано автором. Рабочий перевод. Если у методики есть пороги, они установлены для оригинала; когда появится официальный украиноязычный вариант, сверить с ним.

**Инструкция обследуемому:** Следующие вопросы — о том, как вы себя чувствуете в разных частях своей жизни. Для каждого выберите, насколько часто вы так себя чувствуете.

## 2. Источник

- **Записано в системе** (журнал установки каталога, на языке записи): Three-Item Loneliness Scale, Hughes, Waite, Hawkley, Cacioppo, 2004 (UCLA)
- **Публикация по досье**: Hughes ME, Waite LJ, Hawkley LC, Cacioppo JT. A Short Scale for Measuring Loneliness in Large Surveys: Results From Two Population-Based Studies. Research on Aging. 2004;26(6):655–672. DOI 10.1177/0164027504268574
- **Полосы по досье** (на языке досье): Завести нельзя. В первоисточнике Hughes et al. (2004) полос нет — там вводится только суммарный балл 3–9. Широко ходящее деление "3–5 не одинок / 6–9 одинок" встречается в методичках и руководствах (например Campaign to End Loneliness, каргиверский справочник RGPS Ontario, где прямо сказано "Anything over a score of six (6) should be discussed with a health care professional"), но публикацию, где этот порог УСТАНОВЛЕН автором и провалидирован, найти не удалось: разные работы режут шкалу по-разному. Выдавать только балл 3–9 и динамику; если отделение хочет флаг при ≥6, подписывать его как локальное правило, а не как порог методики.
- **Лицензия по досье**: свободна с условиями — Цитата приведена дословно, вместе с опечаткой оригинала ("to use use" и сбитая вторая половина фразы) — так она напечатана на официальной странице соавтора шкалы Anne Peplau в UCLA, где перечислены все версии, включая "3-item scale designed for use in telephone surveys" (Hughes et al., 2004). ОГРАНИЧЕНИЕ, которое надо видеть честно: разрешение сформулировано для НЕКОММЕРЧЕСКИХ ИССЛЕДОВАТЕЛЬСКИХ целей; клиническое применение в отделении этой фразой прямо не покрыто. Копирайт 20-пунктовой версии 3 принадлежит Daniel W. Russell (Iowa State University), и подтверждение для клинического (не исследовательского) использования стоит запросить у него. Утверждения "шкала в public domain" встречаются в Википедии и на сторонних сайтах — это не первоисточник, опираться на них нельзя.
- **Решение досье** (на языке досье): завести — разрешение есть на официальной университетской странице соавтора, текст трёх пунктов сверен по государственному бланку NIH; НО заводить только балл 3–9 без полос, и для клинического (не исследовательского) применения запросить подтверждение у D. W. Russell.

## 4. Шкалы

### UCLA3 — Уровень одиночества

- **Тип:** клиническая (содержательная)
- **Ключ:** пункты 1–3 (3), балл выбранного варианта
- **Обратные пункты:** нет
- **Сырой балл:** сумма вкладов пунктов; округление до 0,001
- **Нормирование:** нет: итог — сырой балл
- **Диапазон сырого балла:** от 3 до 9
- **Минимальная доля ответов:** 0,8 (общее правило системы) — не меньше 3 из 3 заданных пунктов; меньше — шкала не вычислена (не 0). Пункты, скрытые условием показа, в знаменатель не идут.
- **Описание в системе:** Сумма трёх пунктов, 3–9. Полос нет намеренно: авторы краткой формы порогов не устанавливали. Если отделение захочет поднимать флажок при сумме 6 и более, это должно быть записано как локальное клиническое правило, а не как порог методики.

_Полос нет — система показывает только балл, без интерпретации и без тревоги по баллу._

## 6. Примеры «ответы → результат»

Каждый результат ниже посчитал движок подсчёта системы (`evaluateSubmission` — тот же, что при сдаче на сервере и без сети на устройстве) во время генерации листа. Подобраны: крайние ответы; для каждой шкалы — наименьшее и наибольшее значение и обе стороны каждой границы полос (ближайшие достижимые значения); порог достоверности; каждый критический вариант; пропуски у минимальной доли ответов; для норм по полу — каждый пол и неуказанный пол; проверочные примеры досье. Ответы, не относящиеся к шкале примера, — «самые тихие»: без тревоги и с наименьшим вкладом, прежде всего в шкалы достоверности.

Ответы записаны баллом выбранного варианта — как на бланке, до обращения, — по десять пунктов в строке; «—» — пункт не задавался или остался без ответа, «т» — свободный текст.

**П1.** Все ответы — вариант с наименьшим баллом на бланке

- Ответы: `1–3: 1 1 1`
- Результат: UCLA3 = 3 · полос нет · без тревоги
- Итог: тревог нет · протокол достоверен · предупреждения: нет

**П2.** Все ответы — вариант с наибольшим баллом на бланке (обратные пункты при этом дают наименьший вклад)

- Ответы: `1–3: 3 3 3`
- Результат: UCLA3 = 9 · полос нет · без тревоги
- Итог: тревог нет · протокол достоверен · предупреждения: нет

**П3.** Пропуски в шкале UCLA3: без ответа пункты 3 — ответов 2 из 3, ниже минимальной доли 0,8; шкала не вычислена

- Ответы: `1–3: 1 1 —`; без ответа: 3
- Результат: UCLA3: не вычислено
- Итог: тревог нет · протокол достоверен · предупреждения: Шкала «Уровень одиночества»: ответы есть на 2 из 3 пунктов, нужно не меньше 80 % — балл не вычислен

**П4.** Пример досье: 3 + 3 + 2 → 8

- Ответы: `1–3: 3 3 2`
- Результат: UCLA3 = 8 · полос нет · без тревоги
- Итог: тревог нет · протокол достоверен · предупреждения: нет
- Ожидается по досье: UCLA3 = 8 → система: 8 ✓
