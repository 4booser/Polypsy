# Досье на методики каталога

Четыре файла — результат разведки по первоисточникам (сентябрь 2026):
для каждой методики текст пунктов, якоря, ключ, обратные пункты, полосы с
источником, пометки риска, проверочный пример, состояние украинского
перевода и основание лицензии — с дословными цитатами правообладателей.

Зачем они в репозитории, а не в чьих-то заметках: каждая полоса и каждый
порог в `apps/api/src/instruments/*.ts` обязан сводиться к записи здесь, а
запись — к первоисточнику. Методика без опубликованных полос заводится без
полос (`pss10`, `rses`, `brief_cope`, `ucla3`, `dass42`); чужая норма
называется в описании; рабочий перевод помечен `WORKING_TRANSLATION`.

Поле `verdict` у каждой карточки: «завести», «завести без полос», «завести
без текста (лицензия)» — карточка без пунктов, пока правообладатель не
выдал бланк, — или «не заводить» (правообладатель запрещает открытый
веб, как Mind Garden у STAI). Заявление учреждения о наличии разрешений
закрывает вопрос лицензий, но не вопрос выдуманных порогов: если текста
или порога нет в досье, его нет и в каталоге.

| Файл | Группа | Заводятся с текстом |
|---|---|---|
| `mood.json` | настроение, тревога, дистресс | phq9, gad7, phq4, phq8, cesdr, srq20, gds15, pss10 (без полос), dass42 (без полос) |
| `trauma.json` | травма и военный контекст | pcptsd5, ces, sbqr |
| `function.json` | функционирование, ресурсы, поддержка | mspss, rses, brief_cope, ucla3, osss3 |
| `behaviour.json` | зависимости, внимание, выгорание | cage, auditc, assist, asrs6, cbi |
