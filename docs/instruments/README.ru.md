# Пакет сверки методик

> Для клинического психолога. Сгенерировано из определений методик и живого движка подсчёта (`apps/api/src/instrumentSheets/`); руками не править — только блоки «Проверка психологом» в листах. Перегенерация: `bun run --cwd apps/api docs:instruments`; тест `apps/api/test/instrumentSheets.test.ts` падает, если лист разошёлся с тем, что считает система.
>
> [Українська версія](README.md) · [Как система считает](ru/scoring-rules.md) · [Досье первоисточников](dossiers/README.md)

Методики в системе никто клинически не подтверждал. Этот пакет — по листу на каждую из 31 методик (4 встроенные и 27 из общего каталога), на украинском (`uk/`) и русском (`ru/`). Лист описывает ровно то, что считает система: пункты с баллами, ключи шкал, формулы, нормы, границы полос так, как их читает движок, тревоги, примеры «ответы → результат», посчитанные движком, и всё, что сверить с первоисточником.

## Как работать с пакетом

1. Прочитать [«Как система считает»](ru/scoring-rules.md) — общие правила движка (пропуски, полуинтервал, нормирование, достоверность, риск). В листах они не повторяются.
2. Для каждой методики открыть лист и пройти разделы 3–9 по чек-листу ниже, держа рядом пособие или бланк первоисточника.
3. Результат сверки записать в блоке «Проверка психологом» в начале листа: кто, дата, вывод, замечания, отметки в чек-листе. Этот блок генератор не перезаписывает. После заполнения перегенерировать пакет — столбец «Сверено» в таблице ниже обновится.
4. Замечания (раздел 9 листа и сводка ниже) не исправлены намеренно: пакет — для сверки, а не для изменения подсчёта. Решение по каждому — за психологом.

## Пороги, изменённые в волне 12 — просим проверить

Эти пороги изменены по клиническому ревью без психолога заказчика. Каждый стоит сверить с первоисточником в первую очередь: они меняют, кто получает тревогу.

- **WHO-5** ([лист](ru/who5.md)): 0–7 «Очень низкое благополучие» (тяжёлая); 8–12 «Пониженное благополучие» (умеренная); 13–25 «Без признаков сниженного благополучия» (нет). Источник — WHO, 1998; Topp et al., 2015: ниже 13 — плохое благополучие, 7 и ниже — вероятная депрессия. Раньше 13 из 25 попадало в умеренную полосу с тревогой.
- **СР-45, шкала лжи** ([лист](ru/sr45.md)): протокол ненадёжен при L > 0,5, то есть L ≥ 0,6 (доля из десяти пунктов идёт шагом 0,1). Раньше порог «> 0,6» пропускал ровно L = 0,6.
- **Мини-мульт, нижняя T-полоса** ([лист](ru/minimult.md)): начинается с −14 — самого низкого T, достижимого по нормам пособия (у женщин Pt: M = 14,48, SD = 2,27, так что T при нулевом балле ≈ −13,8). Раньше полоса начиналась с 0, и такой профиль оставался без интерпретации.
- **Минимальная доля ответов** (все шкалы без своего правила): 0,8. Если ответов на пункты шкалы меньше, шкала не вычисляется (а не даёт 0 и полосу «норма»). Для шкалы из 2–4 пунктов это означает «все пункты». Пункты каталога обязательные, поэтому при обычной сдаче правило срабатывает только на частичном ответе.
- **Полуинтервал соседних полос**: границы, записанные с точностью пособия («0,60–0,74 · 0,75–1», «0–4 · 5–9»), читаются как «до начала следующей полосы, не включительно». Проверка движком сейчас: 26/35 = 0,743 → полоса 0,60–0,74. Раньше такое значение проваливалось между полосами — без полосы и без тревоги. Щель шире точности границ остаётся без полосы: её система не выдумывает.

## Чек-лист для психолога

Для каждого листа:

1. **Пункты** (раздел 3): текст, порядок и количество пунктов — как на бланке; варианты ответов и их баллы; обратные пункты; условия показа.
2. **Ключи** (раздел 4): какие пункты входят в каждую шкалу и за какой ответ; вес; поправки.
3. **Формула**: сумма, среднее или количество; нормирование (доля, T-балл, стены) и таблица норм с источником; минимальная доля ответов.
4. **Полосы**: границы «в методике» против пособия; столбец «Как читает система» — приемлемо ли прочтение границы; подписи и рекомендации.
5. **Тревоги** (раздел 5): есть ли основание у критических ответов и полос с тревогой; верна ли тяжесть (умеренная — случай в очереди, тяжёлая — безотлагательно).
6. **Примеры** (раздел 6): пересчитать вручную по пособию хотя бы минимум, максимум, обе стороны одной границы и один критический пункт; для методик с досье — проверочный пример (отметка ✓ / ✗).
7. **Отличия и замечания** (разделы 8–9): принять, отклонить или записать, что изменить.
8. **Запись**: в блоке «Проверка психологом» — ФИО, дата, вывод («сверено» или «есть расхождения») и замечания.

## Замечания для проверки

Общие — касаются нескольких методик или системы в целом:

- **Четыре встроенные методики (СР-45, SAD PERSONS, Мини-мульт, МЛО «Адаптивность-200») ставит только демонстрационный посев** `apps/api/src/seed.ts`; установщик общего каталога их не ставит, а источник в систему не записывается. Посев к тому же не переносит из определения поля эскалации тревоги, порога «слишком быстрого» ответа и показа результата (у Мини-мульта и МЛО они заданы).
- **Тяжесть полос и выбор, какие полосы поднимают тревогу, — решение системы для всех методик**: первоисточники дают границы и подписи, а «умеренная» (случай в очереди) или «тяжёлая» (безотлагательно) — нет. Это стоит проверить по каждой методике (сводка сигналов риска выше).
- **Недостоверный протокол тревог не отменяет**: если шкала достоверности вышла за порог, тревоги по полосам и ответам всё равно поднимаются, а протокол только помечается недостоверным.
- **Переводы**: у большинства методик каталога текст пунктов — рабочий перевод, а пороги установлены для оригинала. Официальные украинские тексты — только у PHQ-9 (и PHQ-2 в PHQ-4, PHQ-8) и CAGE.
- **Досье советовало заводить только английский оригинал** для [Депрессия (CESD-R)](ru/cesdr.md), [Скрининг ПТСР в первичном звене (PC-PTSD-5)](ru/pcptsd5.md), [Боевой опыт (CES)](ru/ces.md), [Суицидальное поведение (SBQ-R)](ru/sbqr.md), [Воспринимаемая социальная поддержка (MSPSS)](ru/mspss.md), [Употребление психоактивных веществ (ASSIST)](ru/assist.md), [Признаки СДВГ у взрослых (ASRS-v1.1, 6 вопросов)](ru/asrs6.md), [Выгорание (Копенгагенский опросник, CBI)](ru/cbi.md); система показывает рабочий перевод — решение учреждения, записанное в описании методики. Пороги у таких методик установлены для англоязычного текста.
- **Паспорт методик `docs/INSTRUMENTS.md` устарел**: пишет о «восьми» методиках каталога (их 27), о 10 непереведённых пунктах МЛО (переведены) и в разделе «Методики, которых здесь нет» до сих пор называет PHQ-9 и GAD-7 защищёнными авторским правом, хотя обе в каталоге.

### [Опросник Мини-мульт](ru/minimult.md)

- Проверка структуры (предупреждение): Шкала достоверности без порога — гейт не сработает. Это законно, если шкала нужна только для поправок — Шкала K.
- Проверка структуры (предупреждение): У содержательной шкалы нет норм — балл будет без интерпретации — Шкала Ma.
- Шкала L (пол: мужской): полосу «Резко выраженный пик» не даёт ни один возможный набор ответов.
- Шкала L (пол: женский): полосу «Резко выраженный пик» не даёт ни один возможный набор ответов.
- Шкала K (пол: мужской): полосу «Резко выраженный пик» не даёт ни один возможный набор ответов.
- Пункт 20 не входит ни в одну шкалу и не отмечен как не считающийся: ответ на него ничего не меняет.
- Источник в системе не записан: его называют только комментарий в определении методики и паспорт docs/INSTRUMENTS.md; журнал установки источника не содержит, потому что методику ставит только демонстрационный посев (seed.ts), а не установщик каталога.
- Страницы источника Мини-мульта в определении (с. 53–88) и в паспорте методик (с. 100–115) разные.
- Тревога по любой базисной шкале с T ≥ 70 не имеет источника; профиль с несколькими пиками поднимает несколько тревог одновременно.
- Определение задаёт эскалацию тревоги через 240 мин и порог «слишком быстрого» ответа 900 мс, но демонстрационный посев (seed.ts), которым методика ставится, эти поля не переносит.
