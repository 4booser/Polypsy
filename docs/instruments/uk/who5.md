## 1. Призначення

П’ять запитань про самопочуття за останні два тижні. Найкоротший опитувальник каталогу. Робочий переклад. Якщо в методики є пороги, їх встановлено для оригіналу; коли з’явиться офіційний україномовний варіант, звірити з ним.

**Інструкція обстежуваному:** Позначте, наскільки кожне твердження описувало ваше самопочуття протягом ОСТАННІХ ДВОХ ТИЖНІВ.

## 2. Джерело

- **Записано в системі** (журнал установки каталогу, мовою запису): WHO-5 Well-Being Index, ВООЗ (Європейське регіональне бюро), 1998

## 3. Пункти

Варіанти відповіді однакові для всіх пунктів (текст — бал): Ніколи — 0; Іноді — 1; Менше половини часу — 2; Більше половини часу — 3; Здебільшого — 4; Увесь час — 5.

Обернений пункт рахується як «мінімум + максимум − бал варіанта» у межах балів цього пункту.

| 3 | Я почувався бадьорим і сповненим сил |   | WHO5 |   |   |

| 5 | Мій день був наповнений тим, що мені цікаво |   | WHO5 |   |   |

## 4. Шкали

### WHO5 — Індекс благополуччя

- **Тип:** клінічна (змістова)
- **Ключ:** пункти 1–5 (5), бал обраного варіанта
- **Обернені пункти:** немає
- **Сирий бал:** сума внесків пунктів; округлення до 0,001
- **Нормування:** немає: підсумок — сирий бал
- **Діапазон сирого балу:** від 0 до 25
- **Мінімальна частка відповідей:** 0,8 (загальне правило системи) — щонайменше 4 з 5 заданих пунктів; менше — шкалу не обчислено (не 0). Пункти, приховані умовою показу, у знаменник не йдуть.

| Смуга | Межі в методиці | Як читає система | Тяжкість | Оцінка | Тривога | Рекомендація, опис |
|---|---|---|---|---|---|---|
| «Дуже низьке благополуччя» | 0 – 7 | від 0 включно до 8 не включно | тяжка | 1 | так — тяжка | Потрібна консультація фахівця та скринінг депресії |
| «Знижене благополуччя» | 8 – 12 | від 8 включно до 13 не включно | помірна | 2 | так — помірна | Рекомендовано пройти опитувальник депресії |
| «Без ознак зниженого благополуччя» | 13 – 25 | від 13 до 25 включно | немає | 3 | ні |   |

## 5. Сигнали ризику

Критичних відповідей немає.

**Смуги, що піднімають тривогу** — лише клінічних шкал і лише за нормованим значенням:

| Шкала | Смуга | Як читає система | Тяжкість |
|---|---|---|---|
| WHO5 | «Дуже низьке благополуччя» | від 0 включно до 8 не включно | тяжка |
| WHO5 | «Знижене благополуччя» | від 8 включно до 13 не включно | помірна |

Підсумкова тяжкість проходження — найгірша з усіх сигналів. Тривоги за пунктами, прихованими умовою показу, не піднімаються. Недостовірний протокол тривог не скасовує.

## 6. Приклади «відповіді → результат»

Кожен результат нижче порахував рушій підрахунку системи (`evaluateSubmission` — той самий, що при здачі на сервері й без мережі на пристрої) під час генерації листа. Підібрано: крайні відповіді; для кожної шкали — найменше й найбільше значення та обидва боки кожної межі смуг (найближчі досяжні значення); поріг достовірності; кожен критичний варіант; пропуски біля мінімальної частки відповідей; для норм за статтю — кожна стать і невказана стать; перевірні приклади досьє. Відповіді, що не стосуються шкали прикладу, — «найтихіші»: без тривоги й із найменшим внеском, насамперед у шкали достовірності.

Відповіді записано балом обраного варіанта — як на бланку, до обернення, — по десять пунктів у рядку; «—» — пункт не задавався або лишився без відповіді, «т» — вільний текст.

**П1.** Усі відповіді — варіант із найменшим балом на бланку

- Відповіді: `1–5: 0 0 0 0 0`
- Результат: WHO5 = 0 · «Дуже низьке благополуччя» (тяжка) · тривога — тяжка
- Підсумок: тривога тяжка («Індекс благополуччя: Дуже низьке благополуччя» — тяжка) · протокол достовірний · попередження: немає

**П2.** Усі відповіді — варіант із найбільшим балом на бланку (обернені пункти при цьому дають найменший внесок)

- Відповіді: `1–5: 5 5 5 5 5`
- Результат: WHO5 = 25 · «Без ознак зниженого благополуччя» (немає) · без тривоги
- Підсумок: тривог немає · протокол достовірний · попередження: немає

**П3.** WHO5: межа «Дуже низьке благополуччя» → «Знижене благополуччя», нижній бік — останнє досяжне значення смуги «Дуже низьке благополуччя»

- Відповіді: `1–5: 5 2 0 0 0`
- Результат: WHO5 = 7 · «Дуже низьке благополуччя» (тяжка) · тривога — тяжка
- Підсумок: тривога тяжка («Індекс благополуччя: Дуже низьке благополуччя» — тяжка) · протокол достовірний · попередження: немає

**П4.** WHO5: межа «Дуже низьке благополуччя» → «Знижене благополуччя», верхній бік — перше досяжне значення смуги «Знижене благополуччя»

- Відповіді: `1–5: 5 3 0 0 0`
- Результат: WHO5 = 8 · «Знижене благополуччя» (помірна) · тривога — помірна
- Підсумок: тривога помірна («Індекс благополуччя: Знижене благополуччя» — помірна) · протокол достовірний · попередження: немає

**П5.** WHO5: межа «Знижене благополуччя» → «Без ознак зниженого благополуччя», нижній бік — останнє досяжне значення смуги «Знижене благополуччя»

- Відповіді: `1–5: 5 5 2 0 0`
- Результат: WHO5 = 12 · «Знижене благополуччя» (помірна) · тривога — помірна
- Підсумок: тривога помірна («Індекс благополуччя: Знижене благополуччя» — помірна) · протокол достовірний · попередження: немає

**П6.** WHO5: межа «Знижене благополуччя» → «Без ознак зниженого благополуччя», верхній бік — перше досяжне значення смуги «Без ознак зниженого благополуччя»

- Відповіді: `1–5: 5 5 3 0 0`
- Результат: WHO5 = 13 · «Без ознак зниженого благополуччя» (немає) · без тривоги
- Підсумок: тривог немає · протокол достовірний · попередження: немає

**П7.** Пропуски у шкалі WHO5: без відповіді пункти 5 — відповідей 4 з 5, не нижче мінімальної частки 0,8; бал рахується за наявними відповідями без перерахунку

- Відповіді: `1–5: 0 0 0 0 —`; без відповіді: 5
- Результат: WHO5 = 0 · «Дуже низьке благополуччя» (тяжка) · тривога — тяжка
- Підсумок: тривога тяжка («Індекс благополуччя: Дуже низьке благополуччя» — тяжка) · протокол достовірний · попередження: немає

**П8.** Пропуски у шкалі WHO5: без відповіді пункти 4, 5 — відповідей 3 з 5, нижче мінімальної частки 0,8; шкалу не обчислено

- Відповіді: `1–5: 0 0 0 — —`; без відповіді: 4, 5
- Результат: WHO5: не обчислено
- Підсумок: тривог немає · протокол достовірний · попередження: Шкала «Індекс благополуччя»: відповіді є на 3 з 5 пунктів, потрібно щонайменше 80 % — бал не обчислено

## 7. Що звірити з першоджерелом

- Текст і порядок пунктів 1–5; варіанти відповідей і їх бали (розділ 3).
- Обернені пункти: немає.
- Ключ WHO5 (5 пунктів) і підсумок: сума, сирий бал, 3 смуг.
- Межі й підписи смуг; окремо — тяжкість смуг і те, які з них піднімають тривогу: у першоджерелах зазвичай є лише межі й підписи, тяжкість задала система.
- Критичні пункти: немає — чи є для них підстава в першоджерелі або рішення відділення.
- Межі 7/8 і 12/13 та тяжкість смуг: помірна тривога вже з 12 балів.

## 8. Відомі відмінності від першоджерела

- Пороги змінено у хвилі 12 за джерелом (WHO, 1998; Topp et al., 2015): 0–7 — дуже низьке благополуччя (тяжка тривога), 8–12 — знижене (помірна), 13–25 — без ознак зниження. Проміжних ступенів вище 13 немає, бо їх немає в джерелі (раніше 13 із 25 потрапляло в помірну смугу з тривогою).
- Система показує сирий бал 0–25; відсотковий індекс (бал × 4) не рахується.
- Текст пунктів — робочий переклад.
