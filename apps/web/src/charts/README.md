# Графики «Виразної» (`apps/web/src/charts`)

Общие графики консоли для экранов Polypsy 2.0. Источник облика —
`.superdesign/ui3/kit/charts.py` и CSS в `kit/page.py`; правила — навык dataviz
и `KIT.md` § 2 и § 8. Всё рисуется plain SVG/HTML без библиотек, только токенами
(`apps/web/src/styles/tokens.css`), в обеих темах.

Мобильные графики сюда не относятся — их делает мобильная основа.

## Правила для экранов

1. **Одна ось.** Двух шкал Y на одном графике нет. Величины разного масштаба —
   два графика рядом или `LineChart` с долями от максимума шкалы.
2. **Цвет следует за сущностью**, в постоянном порядке:
   - один ряд — `var(--series)` (`SINGLE_COLOR`);
   - несколько рядов — `var(--c1)…var(--c4)` (`SERIES_COLORS`, `seriesColor(i, n)`),
     у каждого своя форма метки: c1 круг, c2 квадрат, c3 ромб, c4 треугольник
     (`shapeOf`); методики закреплены: PHQ-9 c1, GAD-7 c2, PCL-5 c3, WHO-5 c4
     (`instrumentMark(code)`);
   - «прочее», «було», фон сравнения — `var(--c5)` (`OTHER_COLOR`);
   - упорядоченные категории (варианты ответа, ступени без тяжести) — лестница
     `var(--h1)…var(--h5)` (у `ShareBar` — `step`);
   - тяжесть — ступени `--sev-0…4` и подложки `--sev-N-bg`, только для клинических
     полос и **всегда со словом** (`SevChip`, `SevDot` с формой);
   - **янтарь** `var(--warn)` (`ATTENTION_COLOR`) — только «требует внимания»;
   - **красный** — только риск для человека: сигнал на оси курса, критический
     ответ в `HeatTable`.
   Хекс в экране запрещён. Прежние имена (`--primary`, `--accent`, `--s1…`,
   `--series-quiet`) ещё работают и ведут на те же значения, но новые экраны берут
   имена набора.
3. **Метки тонкие:** линии 2 px (курс — 3 px), метки r ≥ 4 с кольцом поверхности
   2 px (`Marker`), столбцы ≤ 24 px со скруглением 4 px только у конца данных,
   между сложенными частями — просвет поверхности 2 px, а не обводка.
4. **Легенда** есть всегда при двух рядах и больше (`ChartLegend`,
   `SeriesLegend`); у одного ряда её нет — ряд называет заголовок `Figure`.
5. **Подписи выборочно:** число у конца линии, у курса — у каждого замера (у
   длинного — края и крайние), на столбцах — пока их ≤ 16. Остальное — в подсказке.
   Текст никогда не красится в цвет ряда.
6. **Подсказка у каждого графика**, мышью и с клавиатуры: SVG-графики получают
   фокус (Tab), стрелки ходят по точкам, Home/End — к краям, Esc — убрать
   (`useIndexHover`). Перекрестье — фиолетовый пунктир. Строки HTML-полос
   показывают подсказку по наведению и фокусу (`RowTip`).
7. **Таблица вместо графика** там, где числа сверяют: `Figure table={{ head, rows }}`
   добавляет переключатель «Діаграма / Таблиця».
8. **Малые ячейки.** Там, где сервер прячет число порогом (`smallCellFloor`),
   передавайте `null`: полоса не рисуется, на её месте — «n < 5» с объяснением
   по наведению (`SmallCell`; порог — проп `floor`).
9. **Плиток KPI нет.** `Kpi` — крупное число без заливки и рамки: подпись,
   число 32/800, ход рядом с числом (`spark`), пояснение-сравнение (`hint`).
   Каждое число — со сравнением: «з 1 187 почато», «покинули 91». Ряд таких
   чисел экран может разделить линией сам — он знает, где кончается строка сетки.
10. **Ширина.** SVG рисуется в пикселях контейнера (`useChartWidth`), текст не
    растягивается. Графики должны жить на 1280 px консоли.

## Состав

### `course.tsx`, `courseModel.ts` — график курса

Эталонный график карточки пациента: «краще ↓ / ↑», подписанные полосы тяжести
с границами, межі похибки от старта и граница надёжного улучшения, число у
замера, «сьогодні», сигналы, сессии и неявки, подсказка с перекрестьем
(значение, дата, полоса словом, сдвиг от старта с порогом и словом надёжности,
сдвиг от предыдущего). Подписи межі похибки ставятся только туда, где ничего не
закрывают (`freeSpot`); места нет — подпись уходит, смысл остаётся в легенде и
подсказке.

```tsx
import { CourseChart } from "../charts/course";
import { courseEventsFromTimeline, courseFromDynamics } from "../charts/courseModel";

// scale — ScaleDynamics из api.dynamics(userId); rungs — полосы шкалы методики
// (bands из api.survey(surveyId) или аналитики: { min, max, label, severity })
const data = courseFromDynamics(scale, rungs);
const events = courseEventsFromTimeline(await api.timeline(userId));
<CourseChart title={scale.code} {...data} events={events} />;
```

- `points` — замеры (`t` в мс, `label` — дата экрана, `value`, `band`,
  `incomparable`).
- `rc` — порог надёжной зміни в баллах: MDC95 = 1,96·√2·SEM
  (`reliableThreshold`: из `reliableChange.basis` через `measurementError`, иначе
  из `sem`). `null` — зоны нет, под графиком сказано почему.
- `better` — по полярности полос (`betterOf` → `polarityOfBands`); `null` —
  стрелки нет, сдвиг называется «надійна зміна».
- `events` — `session` (визит done/arrived/in_progress), `noshow`, `planned`
  (booked/confirmed), `signal` (тревога). Номера сессий — по порядку
  проведённых и будущих.
- `now` — «сьогодні»; линия рисуется, только если курс до него дотягивается
  (`todayFits`). `null` — без линии.
- `legend={false}` — без легенды и строки «наведіть…».

**Прогноза нет**: приложение тренд не считает, а «тренд ≈ 11» из трёх точек без
модели выдавал бы догадку за оценку. **Цели курса нет**: в данных приложения её
нет.

## Палитра проверена

`validate_palette.js` навыка dataviz, ряды c1…c4:

- светлая на `#FFFFFF` — все проверки проходят и для соседних пар, и для всех пар
  (худший CVD ΔE 10,8, обычное зрение ΔE 16,0);
- тёмная на `#1E1826` — соседние пары проходят (CVD ΔE 12,9, обычное ΔE 17,3);
  все пары — только первые три цвета. Поэтому в рассеянии и малых множественных
  формах в тёмной теме — не больше трёх цветов, четвёртый ряд держится формой
  метки.

`c5` — нейтральный «прочее / сравнение», в категориальную проверку не входит
(низкая насыщенность — его назначение).
