# Графики «Виразної» (`apps/web/src/charts`)

Общие графики консоли для экранов Polypsy 2.0. Источник облика —
`.superdesign/ui3/kit/charts.py` и CSS в `kit/page.py`; правила — навык dataviz
и `KIT.md` § 2 и § 8. Всё рисуется plain SVG/HTML без библиотек, только токенами
(`apps/web/src/styles/tokens.css`), в обеих темах.

Мобильные графики сюда не относятся — их делает мобильная основа.

## Правила для экранов

1. **Одна ось.** Двух шкал Y на одном графике нет. Величины разного масштаба —
   два графика рядом или `LineChart` с долями от максимума шкалы.
2. **Цвет следует за сущностью**, в постоянном порядке:
   - один ряд — `var(--series)` (`SINGLE_COLOR`);
   - несколько рядов — `var(--c1)…var(--c4)` (`SERIES_COLORS`, `seriesColor(i, n)`),
     у каждого своя форма метки: c1 круг, c2 квадрат, c3 ромб, c4 треугольник
     (`shapeOf`); методики закреплены: PHQ-9 c1, GAD-7 c2, PCL-5 c3, WHO-5 c4
     (`instrumentMark(code)`);
   - «прочее», «було», фон сравнения — `var(--c5)` (`OTHER_COLOR`);
   - упорядоченные категории (варианты ответа, ступени без тяжести) — лестница
     `var(--h1)…var(--h5)` (у `ShareBar` — `step`);
   - тяжесть — ступени `--sev-0…4` и подложки `--sev-N-bg`, только для клинических
     полос и **всегда со словом** (`SevChip`, `SevDot` с формой);
   - **янтарь** `var(--warn)` (`ATTENTION_COLOR`) — только «требует внимания»;
   - **красный** — только риск для человека: кольцо сигнала на замере курса,
     критический ответ в `HeatTable`.
   Хекс в экране запрещён. Прежние имена (`--primary`, `--accent`, `--s1…`,
   `--series-quiet`) ещё работают и ведут на те же значения, но новые экраны берут
   имена набора.
3. **Метки тонкие:** линии 2 px (курс — 3 px), метки r ≥ 4 с кольцом поверхности
   2 px (`Marker`), столбцы ≤ 24 px со скруглением 4 px только у конца данных,
   между сложенными частями — просвет поверхности 2 px, а не обводка.
4. **Легенда** есть всегда при двух рядах и больше (`ChartLegend`,
   `SeriesLegend`); у одного ряда её нет — ряд называет заголовок `Figure`.
5. **Подписи выборочно:** число у конца линии, у курса — у замеров, где оно ни
   на что не налезает (у длинного курса — не больше шести: последний, первый,
   крайние, переломы), на столбцах — пока их ≤ 16. Остальное — в подсказке.
   Текст никогда не красится в цвет ряда. **Подпись не режется многоточием**:
   подписи полос и строк-полос переносятся по словам (`bands.tsx`, `HBars`).
6. **Подсказка у каждого графика**, мышью и с клавиатуры: SVG-графики получают
   фокус (Tab), стрелки ходят по точкам, Home/End — к краям, Esc — убрать
   (`useIndexHover`). Перекрестье — фиолетовый пунктир. Строки HTML-полос
   показывают подсказку по наведению и фокусу (`RowTip`).
7. **Таблица вместо графика** там, где числа сверяют: `Figure table={{ head, rows }}`
   добавляет переключатель «Діаграма / Таблиця».
8. **Малые ячейки.** Там, где сервер прячет число порогом (`smallCellFloor`),
   передавайте `null`: полоса не рисуется, на её месте — «n < 5» с объяснением
   по наведению (`SmallCell`; порог — проп `floor`).
9. **Плиток KPI нет.** `Kpi` — крупное число без заливки и рамки: подпись,
   число 32/800, ход рядом с числом (`spark`), пояснение-сравнение (`hint`).
   Каждое число — со сравнением: «з 1 187 почато», «покинули 91». Ряд таких
   чисел экран может разделить линией сам — он знает, где кончается строка сетки.
10. **Ширина.** SVG рисуется в пикселях контейнера (`useChartWidth`), текст не
    растягивается. Графики должны жить на 1280 px консоли.

## Состав

### `course.tsx`, `courseModel.ts`, `courseGrid.tsx`, `bands.tsx` — график курса

График карточки пациента: врач читает его за десять секунд между приёмами.

- **Шапка словами** (HTML над рисунком): что меряли и чем («Депресія · PHQ-9»,
  `courseNames`), сколько сейчас («19 з 27», у нормированной — «64 T-бал», доля —
  процентом), полоса — плашкой, сдвиг от старта — словом: «значуще погіршення:
  +8 з 13 трав.», «у межах похибки: −3 з …», «значущість не оцінено»,
  «перший замір — порівнювати ще ні з чим». Похибка вимірювання живёт здесь и в
  подсказке, а не полосой поперёк поля.
- **Полосы** тихой заливкой, текущая темнее; подписи — **целиком**, с
  границами («15–19 Середньої тяжкості депресія»), в колонке справа
  (`bands.tsx`: перенос по словам, поле растёт, пока подпись не встанет в свою
  полосу; ушедшая — на подложке с выноской; узкий график — строки под ним).
- **Клинический порог** — один пунктир с плашкой «клінічний поріг ≥ 10»
  (`cutoffOf`: граница, с которой полосы помірні або виражені — то же правило,
  что «у клінічних смугах» на зведенні).
- **«менше — краще / більше — краще»** словами у оси.
- **Сигнал риска** — красным кольцом на том замере, который его поднял
  (`responseId` и код шкалы в строке хронологии, `signalsOn`), а не на оси дня.
- **Дорожка событий** под датами: приём, неявка, запланированный, заключение —
  значками без номеров (`EventGlyph`), с подсказкой и легендой (`CourseLegend`).
- **Подсказка замера** мышью и с клавиатуры: дата, балл, полоса с границами,
  сдвиг от старта со словом и способом оценки (RCI, 95 %), от предыдущего, кто
  заполнял (`source`), сигналы этого замера. Нажатие на замер или Enter —
  протокол прохождения.

```tsx
import { CourseChart, CourseLegend } from "../charts/course";
import { CourseGrid } from "../charts/courseGrid";
import { courseEventsFromTimeline, courseFromDynamics, courseNames } from "../charts/courseModel";

// scale — ScaleDynamics из api.dynamics(userId); rungs — полосы шкалы методики
const data = courseFromDynamics(scale, rungs, undefined, { surveyId });
const names = courseNames(surveyTitle, scale.title, single);
const events = courseEventsFromTimeline(await api.timeline(userId));
<CourseChart title={scale.title} measure={names.measure} method={names.method} {...data} events={events} />;
```

- `points` — замеры (`t` в мс, `label` — дата экрана, `value`, `band`,
  `incomparable`, `href` протокола, `source`).
- `rc` — порог значущої зміни в баллах: MDC95 = 1,96·√2·SEM
  (`reliableThreshold`: из `reliableChange.basis` через `measurementError`,
  иначе из `sem`). `null` — «значущість не оцінено».
- `better` — по полярности полос (`betterOf` → `polarityOfBands`); `null` —
  без «менше — краще», сдвиг называется «значуща зміна».
- `max` — верх шкалы в единицах значения (`pointValueTop`): «з 27» и край оси.
- `events` — `session`, `noshow`, `planned` (прошедший без отметки — «прийом
  без відмітки», по `now`), `conclusion`, `signal` (с `responseId` и `scaleCode`).
- `size="compact"` — малый формат (поле ниже, лишние подписи полос уходят),
  `header={false}` — шапку рисует экран, `legend={false}` — одна легенда на
  сетку (`CourseLegend`).
- Открытые крайние полосы Т-баллов (−14–44,9, 80–200) срезаются до двух
  средних полос за границей — с изломом у оси (`courseDomain`).

`CourseGrid` — сетка графиков без пустых полурядов: столбцов по ширине (график
не уже 420 px, до трёх в ряд), последний неполный ряд растягивается
(`gridSpans`). `CourseSpark` — курс в строке таблицы (96 × 28: полосы, порог,
линия, точка на последнем замере), для таблиц методик.

**Прогноза нет**: приложение тренд не считает, а «тренд ≈ 11» из трёх точек без
модели выдавал бы догадку за оценку. **Цели курса нет**: в данных приложения её
нет. **«Сьогодні» нет**: линия совпадала с последним замером.

`LineChart` (ряды, SEM/межквартильная полоса, `marks`, подписи у концов,
`AxisNote` у срезанной оси), `AxisNote`, `AxisBreak`, `useChartWidth`. Доли —

`StackedArea`, `BarList` и весь `advanced.tsx` (радар, ящик с усами, рассеяние,

## Палитра проверена

`validate_palette.js` навыка dataviz, ряды c1…c4:

- светлая на `#FFFFFF` — все проверки проходят и для соседних пар, и для всех пар
  (худший CVD ΔE 10,8, обычное зрение ΔE 16,0);
- тёмная на `#1E1826` — соседние пары проходят (CVD ΔE 12,9, обычное ΔE 17,3);
  все пары — только первые три цвета. Поэтому в рассеянии и малых множественных
  формах в тёмной теме — не больше трёх цветов, четвёртый ряд держится формой
  метки.

`c5` — нейтральный «прочее / сравнение», в категориальную проверку не входит
(низкая насыщенность — его назначение).
